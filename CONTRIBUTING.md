# Contributing

Read [AGENTS.md](AGENTS.md) before editing. Keep changes within the phase named in the [roadmap](docs/project-management/implementation-roadmap.md).

For documentation changes:

1. Update the authoritative topic document and replace duplicate explanations with relative links.
2. Apply the repository evidence labels consistently.
3. Keep safety blockers and unresolved decisions visible.
4. Validate Markdown links and Mermaid blocks.
5. Confirm that planned work is not described as implemented.

Do not add secrets, credentials, generated deployment manifests, or product source code to this repository.

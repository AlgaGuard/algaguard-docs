# Research index

Record dated research notes here only when they support a Phase 1 or later decision. Each note should distinguish manufacturer/official sources, vendor listings, engineering assumptions, and unresolved facts. Scientific profile templates require supervisor-approved sources and are not present in Phase 1.

Current hardware references are centralized in [hardware inventory](../hardware/hardware-inventory.md); AWS sources are centralized in the [six-month cost plan](../project-management/aws-six-month-cost-plan.md).
